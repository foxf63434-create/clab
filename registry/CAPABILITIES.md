# CAPABILITY REGISTRY

STATUS: ACTIVE

Capability states:
- UNKNOWN
- DISCOVERED
- TRAINING_REQUIRED
- SANDBOX_QUALIFIED
- QUALIFIED
- SUSPENDED

A capability is QUALIFIED only with evidence appropriate to the task. Self-report alone is insufficient.

For missing capability use:
REUSE EXISTING MATERIAL -> FIND TRUSTED MATERIAL -> CREATE MINIMAL TRAINING PACK -> SANDBOX TASK -> INDEPENDENT ASSESSMENT -> QUALIFIED/REJECTED.

Fields:
- CAPABILITY_ID
- DESCRIPTION
- TEAM/AGENT
- STATUS
- SOURCE/TRAINING
- ASSESSMENT
- EVIDENCE
- LIMITATIONS
- LAST_VERIFIED

No remote capabilities are qualified yet. They will be populated from real pilot evidence.
